# Calculator Project

A simple calculator built with HTML, CSS, and JavaScript as part of The Odin Project.

## Features

- Add
- Subtract
- Multiply
- Divide
- Chained calculations
- Clear button
- Divide by zero protection
- Rounded decimal results
- Consecutive operator protection
- Dynamic display updates

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

```text
calculator/
│
├── index.html
├── style.css
└── script.js
```

## How It Works

The calculator stores:

- First number
- Operator
- Second number

When the equals button is pressed, the `operate()` function runs the correct math function and updates the display with the result.

Example:

```text
12 + 7 = 19
```

The calculator also supports chained operations:

```text
12 + 7 - 1 = 18
```
